#  Bella Vista

**Bella Vista** is a clean, modern, and fully responsive landing page website designed entirely using **HTML5 and CSS3**. It focuses on elegant UI layouts, smooth visual transitions, and aesthetic presentation for premium hospitality or real estate aesthetics.

[Live Demo](https://github.com) · [Report Bug](https://github.com/issues)

---

##  Features

- **Pure HTML & CSS:** Zero external heavy frameworks, ensuring blazing-fast load times.
- **Elegant User Interface:** Clean spacing, curated typography, and premium modern visual layout.
- **Fully Responsive:** Custom CSS media queries to ensure smooth layout transitions across mobiles, tablets, and desktops.
- **Smooth Animations:** Lightweight hover effects and hover transitions for enhanced UX.

---

##  Tech Stack

- **Markup:** HTML5
- **Styling:** CSS3 (Custom Variables, Flexbox/Grid)

---

##  How to Run Locally

Since this is a lightweight static site, you don't need any complex installation.

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Open the project:**
   Navigate into the folder and simply double-click the `index.html` file to launch it instantly in any standard web browser.
